
# CUDA C 程序结构

1. 执行从主机代码(CPU串行代码)开始。
2. 当核函数被调用时，会在设备上启动大量线程来执行内核。由内核调用启动的所有线程称为一个**网格**。这些线程是CUDA平台中并行执行的主要载体。
3. 当网格中的所有线程都完成执行时，网格终止，并且在主机上继续执行，直到启动另一个网格。

# 设备全局内存和数据传输

设备通常是带有自己的动态随机访问内存的硬件卡，称为**设备全局内存**，或简称为**全局内存**。
- 例如，NVIDIA Volta V100配备了16GB或32GB的全局内存。
- 称其为“全局”内存，可将其与程序员也可访问的其他类型的设备内存区别开来


申请内存：`cudaMalloc()`
- 在设备全局内存中分配对象
- 两个参数
	- 指向分配对象的指针的地址（`void**`类型）
	- 分配对象的大小，以字节为单位

释放内存：`cudaFree()`
- 释放设备全局内存中的对象
	- 指向已释放对象的指针

数据传输：`cudaMemcpy()`
- 需要四个参数
	- 指向目标位置的指针
	- 指向源位置的指针
	- 已复制的字节数
	- 传输类型/方向
- **符号常量**`cudaMemcpyHostToDevice`和`cudaMemcpyDeviceToHost`是CUDA编程环境的可识别的预定义常量。

>请注意，通过对源指针和目标指针进行适当排序，并为传输类型使用适当的常量，可以使用相同的函数在两个方向上传输数据。

# 核函数和线程

CUDA C编程是众所周知的单程序多数据(SPMD)并行编程风格的实例。

线程**网格**的组织形式：2层结构
- **线程块**（块）：每个块最多**1024**个线程

一些**内置变量**：
- 块中线程数：`blockDim.x .y .z` 对应1 2 3维数组
	- 建议块中每个维度中的线程数是32的倍数
- 坐标：
	- `threadIdx`：块内唯一，线程坐标
	- `blockIdx`：为块中的线程提供公共**块坐标**
- 唯一索引的计算（一维）：`i=blockIdx.x * blockDim.x +threadIdx.x`
