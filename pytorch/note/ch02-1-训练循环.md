**DataSet类**

目前数据准备的状态是手动转为`tensor`张量并上传的，可以进一步**抽象**

在PyTorch 中，数据集由继承自**Dataset类**的常规 Python类表示。
- 可以把它想象成一个**元组列表**，每个元组对应一个点`(特征、标签)`。

**需要实现的方法**
- `__init__(self)`：无须在构造方法(`__init__`)中加载*整个数据集*。如果数据集很大(如成千上万的图像文件),那么一次加载它不会节省内存，建议*按需*加载它们（每当调用`__get_item__`时)
- `__get_item__(self,index)`：索引访问，可返回**预先加载**数据集的相应切片，或者如上所述，**按需加载**
- `__len__(self)`：返回整个数据集大小

使用Numpy数组构建了**训练张量**，但没有将它们发送到设备
- 不希望整个训练数据都加载到GPU张量中，就像迄今为止在示例中所做的那样，因为它占用了*宝贵的显存空间*。
```python
class CustomDataset(Dataset):
	def__init__(self,x_tensor,y_tensor):
	self.x=x_tensor
	self.y=y_tensor
	def__getitem__(self,index):
		return(self.x[index],self.y[index])
	def__len__(self):
		return len(self.x)
#等一下，这是一个CPU张量吗?为什么?.to(device)在哪里x_train_tensor = torch.from_numpy(x_train).float()y_train_tensor = torch.from_numpy(y_train).float()
```

**DataLoader类**

目前的状态：每次训练都用了整个训练数据，一直是**批量梯度下降**，对小的数据集很好。
- 但正常情况还是使用**小批量梯度下降**，所以需要对数据集拆分

> 回顾：之前手动数据集拆分的方法是：随机生成索引取数

PyTorch的**DataLoader类**来完成这项工作
- 要使用哪个数据集
- 所需的小批量大小
- 是否愿意对其进行打乱

>小批量大小，通常使用2的幂，如16、32、64或128,而32似乎是大多数人的选择
>一些更复杂的模型可能使用更大的尺寸，尽管尺寸通常受到硬件限制

> 回顾：大多数情况下需要打乱**训练集**，提高梯度下降的性能，例外是时间序列问题
> 另外：**验证集**和**测试集**也不用打乱，因为没有计算梯度

- **DataLoader类**还可和**采样器**一起使用，获取补偿**不平衡类**的小批量。
- **DataLoader类**的行为类似**迭代器**，可以循环使用，每次获取不同的**小批量**

```python
train_loader =DataLoader(dataset=train_data, batch_size=16,shuffle=True)

next(iter(train_loader))
```
> 不要调用`list(train_loade)`这会破坏**迭代器**的初衷

**模型配置**：保持不变

**模型训练**：处理了几件事情
- 增加循环：注意和之前的区别
	- 随机梯度下降：全量数据训N遍
	- 小批量梯度下降：不同小批量的数据总共训N遍
- 上传GPU：发送的是小批量的数据到GPU，而不是全部
	- 对于更大的数据集，在Dataset的`__get_item__`方法中按需加载数据(到CPU张量中),然后将属于同一小批量的所有数据点立刻发送到您的GPU(设备)上，这是充分利用显卡内存的好方法
- **平均损失**：之前是每个数据点放入损失列表，改为每个周期结束，计算小批量平均损失，再放入列表
- 训练时间长了：调用train函数的次数多了（所以`n_epochs`改为200即可）

>16是小批量大小，总共有80个训练数据点，执行内循环80/16= 5次
```python
#定义周期数
n_epochs = 1000

losses =[]

#对于每个周期……
for epoch in range(n_epochs):
	#内循环
	mini_batch_losses =[]
	for x_batch,y_batch in train_loader:
	#数据集存在于CPU中，小批量也是如此
	#因此，需要将这些小批量
	#发送到模型存在的设备
	x_batch = x_batch.to(device)
	y_batch = y_batch.to(device)

	#执行一个训练步骤
	#并返回此小批量的相应损失
	mini_batch_loss = train_step(x_batch, y_batch)
	mini_batch_losses.append(mini_batch_loss)

	#计算所有小批量的平均损失…--这就是周期损失
	loss = np.mean(mini_batch_losses)

	losses.append(loss)
```

**评估模型**

**评估**：验证对未见过数据的预测错误程度
- 训练步骤函数的前两个步骤（预测+损失函数）
- 模式切换：
	- `train`训练模式
	- `eval`评估模式

模式的区别：以丢弃dropout为例
- dropout是一种用于减少过拟合的常用正则化技术，丢弃在**训练期间**将一些权重随机设置为零。（相当于减去神经网络中的一些节点）；所以要求模型在训练和评估期间表现不同

**模型配置**：预测和计算损失的高阶函数：
```python
def make_val_step_fn(model,loss_fn):
	#在验证循环中构建执行步骤的函数
	def perform_val_step(x,Y):
		#设置模型为评估模式
		model.eval()
		#第1步：计算模型的预测输出——前向传递
		yhat = model(x)
		#第2步：计算损失
		loss = loss_fn(yhat,y)
		#因为在评估期间不更新参数
		#所以无须计算第3步和第4步
		return loss.item()
	return perform_val_step
```

**模型（训练）预测**：
- **禁用梯度计算**：`torch.no_grad()`:尽管它不会对简单的模型产生影响，但最好使用此上下文管理器包裹验证内循环，以*禁用您可能无意触发的任何梯度计算*——梯度属于训练，而不是验证步骤。
```python
#定义周期数
n_epochs = 200

losses =[]
val_losses =[] 

for epoch in range(n_epochs):
 #内循环
 loss = mini_batch(device,train_loader,train_step)
 losses.append(loss)

 #验证---验证中没有梯度
 with torch.no_grad(): 
 val_loss = mini_batch(device,val_loader,val_step) 
 val_losses.append(val_loss)

```

**保存和加载模型**

防止训练中断的途径：
- 检查点
- 保存模型
用途：
- 重新开始训练
- 部署

**模型状态**包括
- `model.state_dict()`: 模型抽象（参数，预测函数）
- `optimizer.state_dict()`：优化器抽象（更新方式）
- losses：跟踪损失的的演变。
- epoch: 运行到的周期
- 想稍后恢复的任何其他内容

**保存**
- 将所有内容包裹到Python字典中，并使用 torch.save()将其全部存储到文件中
- 存到名为model_checkpoint.pth的文件中

```python

checkpoint ={'epoch':n_epochs,
	'model_state_dict': model.state_dict(),
	'optimizer_state_dict': optimizer.state_dict(), 'loss':losses,
	'val_loss':val_losses}
torch.save(checkpoint, 'model_checkpoint,pth')

```
检查点和部署在此对模型的保存手段是一样的。


**恢复训练**

前置任务
- 数据准备
- 模型参数配置
此时会生成一个**未经训练的模型**，然后加载数据：

```python
checkpoint = torch.load('model_checkpoint.pth')

model.load_state_dict(checkpoint['model_state_dict'])

optimizer.load_state_dict(checkpoint['optimizer_state_dict'])

saved_epoch = checkpoint['epoch']

saved_losses = checkpoint['loss']

saved_val_losses = checkpoint['val_loss']

# always use TRAIN for resuming training
model.train()


```
